# Week 3 Day 5 - Utility Class Documentation

## Small Utility Library

A utility class contains reusable helper methods that can be used by
different programs.

In this assignment, I created utility methods for:

- Converting a String to uppercase
- Validating password length
- Printing test results

## Code Reuse

The utility methods are reused in another Java class instead of
writing the same code again.

For example, the password validation method can be called whenever
password validation is required.

## Benefits of Utility Classes

Utility classes help to:

- Reduce duplicate code
- Reuse common methods
- Make code easier to understand
- Make code easier to maintain
- Improve the structure of an automation framework

In QA Automation, utility classes can be used for validations,
waits, screenshots, browser actions, file handling, and test data.
