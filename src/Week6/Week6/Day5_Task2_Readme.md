# Week 6 Day 5 - Mini Project 2

## Objective
Create a login automation framework using Selenium,
Java, TestNG, and Page Object Model (POM).

## Tools
- Java
- Selenium WebDriver
- TestNG
- Maven
- IntelliJ IDEA

## Files
1. Day5_MiniProject2_LoginPage.java
2. Day5_MiniProject2_LoginTest.java

## Test Cases
1. Valid Login - Verify login with correct credentials.
2. Invalid Login - Verify error message for incorrect credentials.

## Execution Steps
1. Open the Java_HW project.
2. Open Day5_MiniProject2_LoginTest.java.
3. Run the TestNG test class.
4. Verify both test results.

## Expected Result
Both login tests should pass.
