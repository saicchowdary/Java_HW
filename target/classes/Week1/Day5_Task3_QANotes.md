# QA Basic Notes

## What is QA?

QA stands for Quality Assurance. It is the process of checking software to make sure it works correctly and meets the requirements. The main goal of QA is to deliver good-quality software to users.

## What is a Test Case?

A test case is a set of steps used to test a particular functionality of an application.

A test case usually contains:

* Test Case ID
* Test Scenario
* Test Steps
* Test Data
* Expected Result
* Actual Result
* Pass or Fail

**Example:**
Test Login Functionality

**Steps:**

1. Open the application.
2. Enter a valid username.
3. Enter a valid password.
4. Click the Login button.

**Expected Result:**
The user should successfully log in to the application.

## What is a Bug?

A bug is a problem or defect in the application. A bug occurs when the actual result is different from the expected result.

**Example:**

**Expected Result:** User should log in successfully.

**Actual Result:** Application shows an error after entering valid login details.

This issue should be reported as a bug.
